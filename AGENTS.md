&#x20;  # Agent instructions for this repository



&#x20;  1. Work only inside this repository. Do not read, write, or list files outside it.

&#x20;  2. Never read, print, store, commit, or upload secrets, credentials, tokens, private keys,

&#x20;     browser data, cookies, or config files that may contain them (e.g. \~/.ssh, \~/.config,

&#x20;     \~/.copilot, .env files).

&#x20;  3. Before editing, explain the intended change and which files it touches.

&#x20;  4. Ask before: installing software, contacting a new network destination, deleting files,

&#x20;     changing Git history, committing, or pushing.

&#x20;  5. Preserve uncommitted user work. Never run destructive Git commands (reset --hard,

&#x20;     clean -f, checkout -- <file>, rebase, push --force).

&#x20;  6. Run `git status` before editing. If there are changes unrelated to the task, stop and ask.

&#x20;  7. Make small, reviewable changes.

&#x20;  8. After editing, show `git diff` and run the smallest relevant test.

&#x20;  9. If something fails, explain the error. Never silently ignore or work around it.

&#x20;  10. Never claim success without checking the result (run the test, show the output).
